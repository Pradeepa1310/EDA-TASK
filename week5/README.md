# Healthcare Data Understanding, Cleaning & Exploratory Data Analysis (EDA)

This project focuses on understanding, cleaning, and performing Exploratory Data Analysis (EDA) on a healthcare dataset using Python. The main objectives are to handle missing and inconsistent data, remove duplicates, categorize patient admissions based on urgency, calculate summary statistics, analyze patient demographics, and visualize important patterns in the healthcare data.

## Objectives

- Understand the structure of the healthcare dataset
- Identify and handle missing values
- Remove duplicate records
- Handle inconsistent values
- Categorize admissions based on urgency
- Calculate billing and hospital stay statistics
- Analyze demographics by medical condition
- Create meaningful data visualizations

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The dataset contains healthcare-related information such as Patient ID, Gender, Age, Medical Condition, Date of Admission, Doctor, Hospital, Insurance Provider, Billing Amount, Admission Type, and Discharge Date.

## Data Cleaning

Data cleaning is performed to improve the quality and consistency of the dataset. The process includes checking missing values, handling missing numerical and categorical values, removing duplicate records, converting date columns into the correct format, and handling inconsistent values.

## Admission Urgency Categorization

Admissions are categorized into three urgency levels:

- Emergency → High Urgency
- Urgent → Medium Urgency
- Routine → Low Urgency

## Hospital Stay Analysis

Hospital stay is calculated using the Date of Admission and Discharge Date. This helps determine how many days each patient stayed in the hospital.

## Summary Statistics

Summary statistics are calculated for important numerical columns such as Age, Billing Amount, and Hospital Stay Days. The analysis includes count, mean, median, minimum, maximum, and standard deviation.

## Demographic Analysis

Patient demographics are analyzed based on Gender, Age, and Medical Condition. The project examines gender distribution and average age across different medical conditions.

## Data Visualization

Matplotlib and Seaborn are used to visualize the data. The project includes charts for admission urgency, gender distribution by medical condition, billing amount, hospital stay, and average patient age.

## Project Workflow

Healthcare Dataset → Data Loading → Data Understanding → Data Cleaning → Missing Value Handling → Duplicate Removal → Inconsistent Value Handling → Admission Categorization → Hospital Stay Calculation → Summary Statistics → Demographic Analysis → Visualization → Insights

## Key Learning Outcomes

This project provides practical experience in data loading, data cleaning, missing-value handling, duplicate removal, inconsistent-value handling, date-time conversion, data grouping, descriptive statistics, demographic analysis, and data visualization using Python.

## Conclusion

This project demonstrates how Exploratory Data Analysis can be used to understand and prepare healthcare data for further analysis. Data cleaning improves data quality, while statistical analysis and visualization help identify useful patterns and trends in patient records.
