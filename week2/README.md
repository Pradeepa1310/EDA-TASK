# Superstore Sales Visualization, Relationship Analysis & Business Insights

## 📌 Project Overview

This project analyzes the **Superstore dataset** using Python, Pandas, Matplotlib, and Seaborn.

The main objective is to visualize sales and profit data, analyze relationships between numerical variables, and generate simple business insights from the dataset.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## 📂 Dataset

The project uses the **Superstore dataset** stored in:

`superstore_raw.csv`

The dataset contains information related to:

- Sales
- Profit
- Discount
- Category
- Sub-Category
- Products
- Customers
- Orders
- Regions

## 🎯 Objectives

The following tasks were performed:

1. Load the Superstore dataset and display the first 5 rows.
2. Create a bar plot showing total Sales for each Category.
3. Create a box plot to visualize Profit distribution.
4. Create a scatter plot between Discount and Profit.
5. Create a correlation matrix for numerical columns.
6. Visualize the correlation matrix using a heatmap.
7. Find the Category with the highest total Profit.
8. Write three simple business insights based on the analysis.

## 📊 Visualizations

### 1. Total Sales by Category

A bar chart is used to compare the total sales generated by each product category.

### 2. Profit Distribution

A box plot is used to understand the distribution of profit and identify possible outliers.

### 3. Discount vs Profit

A scatter plot is used to analyze the relationship between discount and profit.

### 4. Correlation Matrix

A correlation matrix is calculated for the numerical columns in the dataset.

### 5. Correlation Heatmap

A heatmap is used to visually represent the strength and direction of correlations between numerical variables.

## 💡 Business Insights

The analysis helps identify:

- The category with the highest total sales.
- The category with the highest total profit.
- The relationship between discount and profit.
- Correlations between important numerical variables.
- Possible profit and sales patterns that can support business decisions.
